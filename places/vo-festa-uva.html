GIUSI 推荐 · 家门口收获节

9月17–20日 · 核心日9月20日 · 离 Torreglia 约20分钟

这不是酒庄，是整个镇子的收获节。

全家会看到用真葡萄装饰的花车、当地人巡游、19家酒庄集中摆摊，以及广场上从下午一直持续到夜里的吃喝和音乐。

家庭版建议

9月20日15:00左右再去：15:30白天花车之后进入 Villaggio DiVino；19:30还舒服的人继续，其他人可以先回家。想真正进入酒庄而不是逛摊位，则把 Calici in Carrozza 作为9月19或20日的另一条平行路线。

一眼事实

  • 日期：9月17–20日；主花车日9月20日。
  • 车程：从家约20分钟。
  • 推荐停留：4–5小时。
  • 现场：19家酒庄、6个food stalls、日夜两次花车。

先决定哪一种

  • 镇中心版：花车＋wine village，弹性最大。
  • 酒庄版：€35小火车串5家，4小时，强制预约。
  • 司机：指定一人完全不饮酒，不能只写“少喝”。

到现场是什么感觉

把它想成“村镇嘉年华＋葡萄丰收＋露天 wine tasting”，不是坐下来听两小时专业讲解。

花车 · 15:30 / 20:30

白天与夜间花车

同一批作品，两种气氛

15:30从 Consorzio Agrario（Via IV Novembre 156）出发，20:30在Piazza Liberazione再走夜场。提前站定看一轮即可，不必追着花车移动。

  • 白天看装饰、当地人和全貌
  • 夜场灯光与音乐更热闹，选看
酒＋食物 · 周日10:00–24:00

Villaggio DiVino

19家酒庄＋6个食物摊

€15 tasting kit 含杯、杯套与8个tokens；refill €15/10 tokens。普通酒2枚、reserve 3枚。先走一圈看酒单，再按下方顺序喝。

  • 周五/六18:30–24:00
  • 周日10:00–24:00
9/19 或 9/20 · 需预约

Calici in Carrozza

€35 / 成人 · 4小时 · 5家酒庄

票含小火车、杯和18个tokens，每30分钟发车；停Ca’ del Colle、Vigna Vecchia、Contarato、Vigna Roda和Tenuta sul Monte。官方明确雨天照常。

  • 9/1910:00–18:00出发
  • 9/2009:00–12:00出发

9月20日照着这样走

这是从Torreglia轻松出发的版本。若当天刚完成长途转场，直接跳到18:30太累版，不把花车变成任务。

上午Torreglia留白

不订酒庄、不逛第二座村。慢早餐、买菜或在家休息。

12:30–14:15家里轻午餐

别先吃正式长午餐；喝水、休息，把胃口和酒量留给Vo’摊位。

14:35从 villa 出发

先试官方大停车区 Via Luigi Einaudi；满位再按现场导向 Via Cairoli、Via Risorgimento 或 Area Campo Fiera。

15:30看白天花车

站定看完整一轮，不需要跟着花车跑。人多时把手机和钱包放好。

16:45买 tasting kit

按实际饮酒人数购买；如想共用杯或tokens先问工作人员。指定司机完全不喝酒。

18:00用摊位解决晚饭

选 cicchetti 和单份小吃，不要追求正式餐厅。坐下后再决定是否留下。

19:30做一次状态判断

此时已完成花车、当地酒和晚饭；想回家的人无需为了夜场硬撑。

20:30夜场是加分项

灯光下花车会再巡游一次。想看的人留下即可，不必要求四个人为了“来都来了”一起硬撑。

四杯把本地喝明白

  1. Serprino：先试轻快起泡，Vigna Roda的Rebégolo可作目标。
  2. Fior d’Arancio secco：明确问dry，Ca’ del Colle可作目标。
  3. sur lie白酒：若当天有瓶中二次发酵版本，再理解低干预路线。
  4. Colli Euganei Rosso：最后试Merlot / Cabernet / Carménère blend。

具体酒款以当日摊位酒单为准；甜Fior d’Arancio与passito放最后少量试。

停车与吃饭

  • 默认：Z.A. Via Luigi Einaudi，官方列约150位。
  • 主场：Piazza Liberazione。
  • 食物：Sapori Veneti（市政府柱廊）或Taverna del Leonicus（Piazzetta Martiri）。
  • 先买水和食物，再开始tasting。

三个执行版本

当天回程和天气都可能影响体力，直接选一个，不需要临场纠结。

完整但不累

15:00–20:00

白天花车＋wine village＋摊位晚饭；信息量、体力和回家时间最平衡。

只想看气氛

18:30–21:30

只做wine village、食物和20:30夜场；适合白天已有安排。

真正看酒庄

Calici · 约4小时

9/19白天或9/20上午串五家酒庄；比市集更有内容，也更依赖预约。

四人预算

  • Festival：2–4套kit €30–60＋food €80–120＋水/软饮€15–25＝约€125–205。
  • Calici：4位成人€140＋之后吃饭€80–120＝约€220–260。

共用kit或杯必须现场确认；预算不以驾驶者饮酒为前提。

天气 / 售罄 fallback

  • Calici售罄：保留15:30花车＋Villaggio。
  • 小雨：Calici官方照常；花车是否调整看主办方公告。
  • 大雨或极度疲惫：只做有遮蔽的wine village与餐饮，或留在家。
  • 不想喝酒：花车＋food stalls本身仍是完整体验。
